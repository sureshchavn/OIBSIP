# Tempora – Smart Temperature Converter 🌡️

Tempora is a simple and responsive temperature converter web application that converts temperatures between Celsius, Fahrenheit, and Kelvin.

## Features

- Convert Celsius to Fahrenheit and Kelvin.
- Convert Fahrenheit to Celsius and Kelvin.
- Convert Kelvin to Celsius and Fahrenheit.
- Simple and user-friendly interface.
- Swap temperature units.
- Convert button for temperature calculation.
- Clear button to reset the converter.
- Supports decimal and negative temperatures.
- Input validation for empty and invalid values.
- Absolute zero temperature validation.
- Accurate conversion calculations.
- Responsive design for mobile and desktop.

## Temperature Conversion Formulas

**Celsius to Fahrenheit**

°F = (°C × 9/5) + 32

**Fahrenheit to Celsius**

°C = (°F − 32) × 5/9

**Celsius to Kelvin**

K = °C + 273.15

**Kelvin to Celsius**

°C = K − 273.15

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all four files are in the same folder.
4. Open `index.html` in your browser.
5. Enter a temperature value.
6. Select the From and To units.
7. Click the Convert Temperature button.
8. View the converted result.

You can also run the project using the VS Code Live Server extension.
