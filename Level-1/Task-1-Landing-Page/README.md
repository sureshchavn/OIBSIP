# VoltDrive – Premium Electric Vehicle Landing Page

A modern, premium, and responsive landing page for VoltDrive, a fictional electric vehicle brand. This project focuses on elegant UI design, modern web technologies, and an engaging user experience.

## 🚀 Project Overview

VoltDrive showcases a premium electric vehicle brand through a cinematic hero section, vehicle collections, advanced technology features, and charging information.

The website uses a dark theme with minimalist typography, elegant layouts, and interactive elements to create a professional automotive landing page.

## ✨ Features

- Premium dark-themed UI design
- Responsive navigation bar
- Cinematic hero section
- Brand philosophy section
- Electric vehicle showcase
- Vehicle category filters (Sedan, Coupe, SUV)
- Technology and engineering section
- EV charging information section
- Customer testimonials
- Newsletter subscription form (frontend demo)
- Responsive layout for mobile, tablet, and desktop
- Smooth scrolling and hover animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Google Fonts
- Material Symbols

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd VoltDrive
```

3. Open `index.html` in your browser.

Alternatively, use the VS Code Live Server extension to run the website.
