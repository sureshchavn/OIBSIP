## Level 1 – Tasks

### Task 1: Landing Page – VoltDrive

A modern landing page project designed with a clean layout and responsive user interface.

**Technologies:** HTML, CSS, JavaScript

**Features:**
- Modern landing page design
- Responsive layout
- Attractive sections and navigation
- Interactive UI elements

### Task 2: Personal Portfolio Website

A personal portfolio website showcasing my profile, technical skills, projects, education and contact information.

**Technologies:** HTML, CSS, JavaScript, Tailwind CSS

**Features:**
- Personal introduction
- About Me section
- Technical skills
- Projects showcase
- Education and experience
- Contact section
- Responsive design

### Task 3: Temperature Converter – Tempora

A simple and user-friendly temperature converter that converts values between Celsius, Fahrenheit and Kelvin.

**Technologies:** HTML, CSS, JavaScript

**Features:**
- Celsius, Fahrenheit and Kelvin conversion
- Swap temperature units
- Convert and Clear buttons
- Decimal and negative temperature support
- Input validation
- Accurate conversion results
- Responsive interface
